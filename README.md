# Rogii Wellbore Geology

Project for wellbore geology analysis and modeling.

## Project Structure

```
rogii-wellbore-geology/
├── data/
│   ├── raw/          # Raw input data
│   └── processed/    # Cleaned and transformed data
├── notebooks/        # Jupyter notebooks for exploration and analysis
├── src/              # Source code
├── models/           # Trained models and artifacts
├── outputs/          # Generated reports, figures, and exports
├── README.md
├── requirements.txt
└── .gitignore
```

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate   # Windows
pip install -r requirements.txt
```

## Usage

Add your notebooks to `notebooks/`, source modules to `src/`, and place raw data in `data/raw/`.
